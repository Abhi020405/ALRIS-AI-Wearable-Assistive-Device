# ALRIS – AI-Powered Wearable Assistive Device

**Final Year Major Project | Ongoing**
**Role:** Team Leader & Technical Lead

## 📌 Overview

ALRIS is an **AI-powered wearable assistive device** being developed to help visually impaired users perceive and navigate their surroundings. The system combines **AI, computer vision, embedded processing, sensors, and audio feedback** to provide real-time environmental information and assistive alerts.

## 🚀 Key Features

* Real-time **object and obstacle detection**
* AI-based **computer vision and image processing**
* Sensor-based **environmental perception**
* Real-time embedded data processing
* **Audio feedback** for detected objects and obstacles
* Compact and wearable system design
* Hardware-software integration and real-time testing

## 🛠️ Technologies

**Python | C/C++ | AI/ML | Computer Vision | OpenCV | Embedded Systems | Sensors | Camera Interface | GPIO | UART | I²C | SPI | Git/GitHub**
